# Repository Rules

## Purpose

Define how the WoodPile repository is maintained.

## Rules

- One authoritative document for each subject.
- Stable filenames.
- Complete replacement documents; never cumulative patches.
- Update `StorageMap.md` whenever documents are added, removed, renamed, or moved.
- Do not duplicate standards between documents.
- Tool Specifications define behavior.
- Engineering Notes preserve discoveries.
- Reference Library preserves reusable knowledge.
- Source code is implementation evidence.
- The repository is the project's authoritative state.
