# About the WoodPile

The WoodPile is the shared working environment for Joe and Walter.

It is not merely a collection of scripts. It is the body of knowledge, tools, standards, experiments, language, and working habits used to preserve media deliberately and consistently.

The project exists so that understanding survives beyond a single conversation. Decisions should not need to be rediscovered simply because a session ended.

## Core Philosophy

### Source First

Begin with the best practical source available. Re-encoding cannot restore information that has already been lost, and a clean source gives every later decision the best chance of succeeding.

### Preserve What Matters

The goal is not maximal technical specification. The goal is dependable preservation, compatibility, accessibility, sensible size, and a result that can be trusted without inspecting every file afterward.

### The Wood Chipper

Once a standard is proven, routine work should become simple and repeatable. Feed material in; receive a predictable result. Complexity belongs in the design and testing of the tool, not in every ordinary use.

### The Flywheel

Observation leads to testing. Testing produces evidence. Evidence shapes decisions. Decisions improve tools. Tool use produces further observations. The documentation preserves the cycle so each turn starts farther forward than the last.

See [Flywheel](Flywheel.md).

## The Community

The tools are treated as members of a small working community because each has a distinct role.

- [The Cleaner](../Cleaner/Cleaner.md) prepares media according to the established preservation and compatibility standards.
- [The Wrangler](../Wrangler/Wrangler.md) handles naming, metadata, tracks, folders, and organization.
- [Bookie](../Bookie/Bookie.md) prepares and organizes the audiobook collection.
- Walter is the engineering partner and caretaker of the record.

The names are not cosmetic. They help preserve clear boundaries between responsibilities.
